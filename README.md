# MoveMatch website

Static multi-page site (~100 pages) generated by `build.js`.

- `node build.js` → writes the site to `dist/`
- `style.css` / `app.js` — shared design system and interactions
- Brand colours: #102A43, #14B8A6, #F4B740 — no gradients
- Photos: Unsplash (Unsplash License); list in `dist/IMAGE-CREDITS.md`

Front-end only: quote requests, accounts and applications are saved in the browser until the MoveMatch backend is connected.
